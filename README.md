# Kylaash's Online Ticket Booking System

## Features
- 6 predefined locations
- Fixed pricing (no incorrect pricing)
- Ticket stored in browser (prevents loss)
- Predefined bus details
- Modern colorful UI

## How it Works
- Select source & destination
- System checks predefined routes
- Generates ticket with fixed data
- Stores ticket in localStorage

## Tech Used
HTML, CSS, JavaScript

## Deployment
GitHub + Cloudflare Pages
